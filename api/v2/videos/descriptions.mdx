---
title: "Video Description"
openapi: "/openapi-v2.json POST /api/v2/videos/descriptions"
---

Describe visible events and scene boundaries in a video. Returns a `request_id` for status polling.

<Note>
**Prerequisite:** Consult the [Model Selection](/api/v2/utilities/models) endpoint to identify a valid model `slug` and check supported presets and duration limits.
</Note>
