<Warning>
  **The v1 prompt boosters have been removed.** They return **410 Gone** with a `Deprecation: true` header and a `Link` header pointing at the successor. There is no automatic redirect — you must update both the URL and the request fields.

  Use the [**v2 Prompt Booster**](/api/v2/prompt-enhancement/prompt-booster) — `POST /api/v2/prompts/enhancements`.
</Warning>

## Migrating

v2 replaces all four boosters with one endpoint. Select the booster with `type` and the target model with `model_slug`.

| v1 endpoint (410 Gone) | v2 replacement |
| --- | --- |
| `POST /api/v1/client/prompt/image` | `type: images.generations` |
| `POST /api/v1/client/prompt/image2image` | `type: images.edits` |
| `POST /api/v1/client/prompt/video` | `type: videos.generations` |
| `POST /api/v1/client/prompt/speech` | `type: audio.speech` |

The four `/price-calculation` variants map the same way to `POST /api/v2/prompts/enhancements/price`.

See the [v2 Prompt Enhancement overview](/api/v2/prompt-enhancement/overview) for the full field reference.
