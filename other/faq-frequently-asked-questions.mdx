#### 1. **How do I get access to the deAPI panel?**

Register or log in (also via Google OAuth) and after authentication you will automatically gain access to the Control Panel, where you can directly create an API key and get access the full capabilities of the platform.

---

#### 2. **How can I get my API key?**

Simply sign up or log in, then navigate to your Dashboard → Settings → API Keys and click "Create new secret key" to instantly generate your API key. For key roles, expiration, spend limits and IP allowlists, see [API Keys](/api-keys).

---

#### 3. **Do I need to fund my account before using the API?**

**No.** Upon registration, you receive a **\$5 bonus** to get started immediately with Basic rate limits. You do not need to make a payment to start testing. Once you make **any payment** (top-up), your account automatically upgrades to **Premium**. If you top up within 30 days of creating your account, your remaining bonus balance carries over after the upgrade. Otherwise the bonus expires (see the next question). See [Limits & Quotas](/limits-and-quotas) for the RPM and daily request limits configured for each endpoint and model.

---

#### 4. **Does the \$5 sign-up bonus expire?**

**Yes, unless you top up.** The bonus is valid for **30 days from the date the account was created** (not from email verification). Any credit purchase within those 30 days keeps whatever is left of the bonus on your account, with no further expiry. If you make no purchase in that window, the unused bonus is removed when the 30 days end. If your balance was only bonus credit, it drops to \$0. A purchase made after the window has closed does not bring an expired bonus back.

**Purchased credits do not expire** while your account remains active and in good standing.

**Accounts created before November 5, 2026:** the 30-day window started on November 5, 2026 and ends on **December 5, 2026**. If you already bought credits before November 5, 2026, your bonus is safe and will not expire.

The full rules are in our [Terms of Service](https://deapi.ai/terms-of-service), section 5.1.

---

#### 5. **Are unused accounts deleted?**

**Yes.** An account is permanently deleted if **all** of the following are still true **60 days after it was created**:

- the balance is \$0,
- no request (inference) has ever been sent from it,
- no API key has ever been created for it.

If any of these does not apply (you have a balance, have run at least one request, or have created an API key), the account is not deleted under this rule. Before deletion we send a notice to the account's verified email address. Deletion cannot be undone. You can register again at any time, but **a new account created after such a deletion does not receive the \$5 bonus again**.

For accounts created before November 5, 2026, the 60 days count from November 5, 2026, so none of them will be deleted under this rule before **January 4, 2027**. See [Terms of Service](https://deapi.ai/terms-of-service), section 15.4.

---

#### 6. **How is authentication handled?**

Every API request requires an `Authorization` header with your personal token:

```text
Authorization: Bearer YOUR_API_KEY
```

---

#### 7. **How do I retrieve the results of my tasks?**

After submitting a task, you'll receive a `request_id`. Use this ID with the **Get Job Results** endpoint (`GET /api/v2/jobs/{request_id}`) to fetch your generated image, video, audio, or transcription.

---

#### 8. **Are there any rate limits?**

**Yes.** RPM and daily request limits vary by endpoint, model, and account tier. Check [Limits & Quotas](/limits-and-quotas) for the values. Some models have the same RPM on Basic and Premium; Premium daily quotas are model-specific. Throttled requests return `429 Too Many Requests`. For High Volume Production requirements beyond the published limits, please contact support.

---

#### 9. **Can I choose between different AI models?**

Yes. Visit the **Model Selection** endpoint to browse available models, or check the **Models** page for a complete list. You can specify the desired model using the `model` parameter when making API requests.

---

#### 10. **What file types are supported?**

**Video** (Transcription, Animation, Upscale):

- Max size: 50 MB
- Supported formats: MP4, MPEG, MOV, AVI, WMV, OGG

**Audio** (Audio-to-Text):

- Max size: 20 MB
- Supported formats: AAC, MP3, OGG, WebM

**Images** (Image-to-Image, OCR, Background Removal):

- Max size: 10 MB (dimensions: 64–5000 px per side)
- Supported formats: JPG, JPEG, PNG, GIF, BMP, WebP

<Note>
  Every API request is also subject to a global **75 MB request body cap** (input) and **100 MB job result cap** (output). For full details see [Limits & Quotas → File Uploads](/limits-and-quotas#file-uploads).
</Note>

#### 11. **What services does deAPI offer?**

deAPI provides the following AI-powered services (v2 REST API):

- **Image Generation** — `/api/v2/images/generations`
- **Image Edit** — `/api/v2/images/edits`
- **Image OCR** — `/api/v2/images/ocr`
- **Image Background Removal** — `/api/v2/images/background-removals`
- **Image Upscale** — `/api/v2/images/upscales`
- **Video Generation** — `/api/v2/videos/generations`
- **Video Animation** — `/api/v2/videos/animations`
- **Video Audio Sync** — `/api/v2/videos/audio-syncs`
- **Video Upscale** — `/api/v2/videos/upscales`
- **Text-to-Speech** — `/api/v2/audio/speech`
- **Text-to-Music** — `/api/v2/audio/music`
- **Transcription** (unified audio/video) — `/api/v2/audio/transcriptions`
- **Text-to-Embedding** — `/api/v2/embeddings`
- **Prompt Enhancement** — `/api/v2/prompts/enhancements`

#### 12. **Can I use deAPI with AI assistants like Claude or Cursor?**

Yes! deAPI offers an **MCP (Model Context Protocol) server** that allows AI assistants and IDE extensions to call deAPI capabilities as structured tools. You can connect Claude, Cursor, and other MCP-compatible clients to generate images, transcribe videos, and more directly within conversations. See the **MCP Server** documentation for setup instructions.

---

#### 13. **Can I use deAPI with n8n or other automation tools?**

Yes! deAPI works seamlessly with **n8n** and other workflow automation platforms. You can build automated workflows that generate images, transcribe videos, create speech, and more using deAPI's HTTP API. The integration uses standard HTTP Request nodes with Bearer token authentication. See the **n8n Integration** documentation for a complete step-by-step guide with example workflows.

---

#### 14. **Can I use deAPI with the OpenAI SDK?**

Yes. deAPI exposes an **OpenAI-compatible** endpoint at `https://oai.deapi.ai/v1`. Set `base_url` (and your `api_key`) on the official OpenAI SDK and your existing code keeps working — only `model` needs to be a deAPI slug (e.g. `Flux1schnell`, `Kokoro`, `WhisperLargeV3`, `Bge_M3_FP16`). Supported endpoints: image generation, image edits, text-to-speech, transcription, embeddings, and video generation. Chat completions and inpainting are not in scope. See [OpenAI Compatibility](/openai-compatibility) for the full guide.

---

#### 15. **What's the difference between v1 and v2?**

- **v2** (current) — Resource-based URLs (`/api/v2/images/generations`, `/api/v2/videos/upscales`), unified transcription (`/api/v2/audio/transcriptions` replaces 5 separate v1 endpoints) and a unified prompt booster (`/api/v2/prompts/enhancements` replaces the per-type v1 boosters).
- **v1** (**deprecated**) — Task-based URLs (`/api/v1/client/txt2img`, `/api/v1/client/vid-upscale`). Existing integrations keep working, but v1 is no longer developed: new endpoints, parameters, models and fixes land in v2 only. Plan a migration.

Both versions share authentication, rate limits, webhooks, and the same model catalog, and jobs live in one namespace — a `request_id` from a v1 call can be polled with `GET /api/v2/jobs/{request_id}` and vice versa. Switch between them using the **API v2 (Latest)** and **API v1 (Deprecated)** tabs at the top of this site.

#### 16. **Is deAPI ready for production use?**

Yes. deAPI is built to support production workloads. Before choosing a model, check its RPM and daily request limits on [Limits & Quotas](/limits-and-quotas); limits vary by endpoint and model, including on Premium accounts.

#### 17. **What should I do if I get an error?**

Check the error code and make sure:

- `401` — Your API key is valid
- `403` — Your account has sufficient permissions
- `429` — You haven't exceeded rate limits
- `500` — Server error (check [status.deapi.ai](https://status.deapi.ai/))

Also verify your request parameters are correct. If the issue persists, contact our support team at [**support@deapi.ai**](mailto:support@deapi.ai) or join our [Discord](https://discord.com/invite/UFfK5YRBsr) for help.
