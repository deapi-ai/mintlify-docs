## Python SDK

The official Python SDK for deAPI. Generate images, videos, audio, transcriptions, embeddings, and more — through a type-safe Python interface with sync and async support.

### Installation

```bash
pip install deapi-sdk
```

**Requirements:** Python 3.11+

<Note>
  The package is `deapi-sdk` and you import it as `deapi_sdk`. `pip install deapi` installs an unrelated package.
</Note>

### Quick Start

```python
from deapi_sdk import DeapiClient

# Reads the key from the DEAPI_API_KEY environment variable,
# or pass it: DeapiClient(api_key="sk-dp-...")
client = DeapiClient()

# Generate an image. Width, height and steps come from the model's own defaults
# unless you set them.
job = client.images.generate(
    prompt="a cat floating in a nebula, photorealistic",
    model="Flux_2_Klein_4B_BF16",
)

# Wait for the result (polls with exponential backoff)
result = job.wait()
print(result.result_url)
```

Async works the same way with `AsyncDeapiClient`:

```python
import asyncio
from deapi_sdk import AsyncDeapiClient

async def main():
    async with AsyncDeapiClient() as client:
        job = await client.images.generate(prompt="a lighthouse at dusk", model="Flux1schnell")
        result = await job.wait()
        print(result.result_url)

asyncio.run(main())
```

### Features

- **Full API coverage** — images, video, audio (TTS, voice cloning, music), transcription, embeddings, OCR, prompt enhancement, models, account, usage and API keys
- **Sync + Async** — `DeapiClient` and `AsyncDeapiClient`
- **Model defaults** — parameters you leave out are filled from the model's own card
- **Job polling** — automatic exponential backoff with `.wait()`
- **Auto-retry** — built-in retry on rate limits (429) and server errors (5xx), honouring `Retry-After`
- **Typed errors** — e.g. `AuthenticationError`, `InsufficientBalanceError`, `RateLimitError`, `NotFoundError`
- **Type-safe** — full type hints, Pydantic v2 models, `py.typed` marker
- **Webhook verification** — HMAC-SHA256 signature validation
- **Price calculation** — every method has a `_price` counterpart to check cost before submitting

## OpenAI SDK (drop-in compatible)

deAPI also exposes an OpenAI-compatible endpoint at `https://oai.deapi.ai/v1`. If you're already using the official OpenAI SDK in any language, you can route image generation, text-to-speech, transcription, embeddings, and video generation to deAPI by changing only `base_url` and `api_key` — your existing code stays unchanged. This works with Python, Node.js / TypeScript, Go, Java, .NET, and any framework that accepts a `base_url` parameter (LangChain, LlamaIndex, Vercel AI SDK).

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",  # the same deAPI key as for the native API, e.g. "sk-dp-1234-AbCdEf..."
    base_url="https://oai.deapi.ai/v1",
)

response = client.images.generate(model="Flux1schnell", prompt="...", size="1024x1024", n=1)
```

## MCP Server

For AI assistants and coding tools (Claude, ChatGPT, Cursor, VS Code, Claude Code, Codex, Gemini CLI), deAPI runs a hosted MCP server at `https://mcp.deapi.ai/mcp`: the assistant calls deAPI as tools, and you sign in with your API key in a deAPI window. The server is open source and published as [`deapi-mcp`](https://pypi.org/project/deapi-mcp/) for self-hosting.
